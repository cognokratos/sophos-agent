# Story 3.3: Browse and Resume Conversations

**Status:** Draft

---

## Story

**As a** user,
**I want** to see a list of my past conversations and be able to select one to continue,
**so that** I can easily switch between different topics or review previous discussions.

---

## Acceptance Criteria

1.  A list of previous conversations is displayed in the UI, for instance, in a sidebar.
2.  Each item in the list clearly identifies the conversation (e.g., using a title, a summary of the first message, or the creation date).
3.  Selecting a conversation from the list loads its full message history into the chat window.
4.  The currently active conversation is visually highlighted in the list.
5.  The list updates automatically when a new conversation is created.

---

## Tasks / Subtasks

-   [ ] **Backend:** Create an endpoint that returns a list of all existing conversation files.
-   [ ] **Frontend:** Design and implement a UI component (e.g., a sidebar) to display the list of conversations.
-   [ ] **Frontend:** Fetch the list of conversations from the backend when the application loads.
-   [ ] **Frontend:** Implement the selection logic, so clicking a conversation loads its content.
-   [ ] **Frontend:** Ensure the conversation list is updated in real-time when a new chat is created.
-   [ ] **Frontend:** Add a visual indicator for the currently active chat.

---

## Dev Notes

-   The conversation list should be easily scannable. Consider what information is most useful for a user to identify a conversation.
-   For performance, the endpoint should only return metadata (e.g., filenames, creation dates, maybe the first line) rather than the full content of every file.
-   The frontend will need to manage the state of the conversation list and the currently selected conversation.

### Testing

-   Unit tests for the conversation list UI component.
-   Integration test to verify the frontend correctly displays the list of conversations provided by the backend.
-   E2E test to simulate a user browsing their conversations, selecting one, and resuming the chat.
